### Smart Content Generator with Sentiment Control

A full-stack web application that generates AI-powered text with real-time sentiment analysis and tone control. Users can generate content with specific emotional tones (positive, negative, or neutral) and see instant sentiment analysis results.

## Features

AI Text Generation
Sentiment Control(Positive, Neutral, or Negative)
Real-time Sentiment Analysis
Visual Feedback*
Sentiment Meter
Request vs Actual Comparison
Word Count Analysis
Fallback System
Responsive Design

### Frontend
React.js
Axios
CSS-in-JS

### Backend
Node.js
Express.js
Axios
CORS - Cross-origin resource sharing

### APIs
Pollinations.ai- Free text generation API (no key required)
Custom Sentiment Analysis** - Word-based algorithm (no API key needed)

### Prerequisites
Before you begin, ensure you have installed:
Node.js(v14 or higher)
npm (v6 or higher)
